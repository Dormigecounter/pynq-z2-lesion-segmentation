# ISIC2018 微调与分割改进（2026-10-26）

本次保留旧发布包与 FPGA bitstream，用发布包中的真实 FP32 权重初始化同结构 SmallUNet。新模型目录为 `artifacts/models/isic2018`，训练和评估证据位于 `artifacts/isic2018`。不要用旧模型的策略文件覆盖新模型策略。

## 数据与隔离

输入为用户提供的 `ISIC2018_Task1-2_Training_Input.zip` 和 `ISIC2018_Task1_Training_GroundTruth.zip`。直接读取 ZIP，不需展开约 11 GB 原图。逐张校验尺寸、二值标注、EXIF 方向，并记录压缩文件成员、原始文件散列及解码像素散列。

共 2594 对：1819 训练、217 验证、217 内部留出测试、341 旧测试重叠排除。新验证与测试集仅来自旧清单完全未出现的 ID/像素组。旧验证图像可以进入本轮训练，因此旧验证分数不能继续用作本轮独立验证。内部留出测试不是官方 ISIC2018 挑战赛测试集；无患者标识，不能保证患者级隔离或排除所有近重复图像。

划分种子为 20261026。验证集选择模型和后处理，测试集只在策略冻结后评估。对比在同一套留出图像上进行，不将旧 ISIC2016 的平均指标与新数据集直接比较。

## 算法与显示

- 保持输入 128×128 和通道 16/32/64/128，使用旧权重、小学习率 0.0001、BCE+Dice 损失、最多 20 轮、5 轮无提升早停。
- 新增配对旋转、缩放、平移、翻转和轻度颜色扰动；标签和有效域使用最近邻，RGB 使用双线性。
- `Parameters.refine=True` 时先反量化连续 logits，裁去 letterbox 补边，双线性恢复原图尺寸，再阈值化。此最终细化在 ARM/CPU 上执行，不宣称 FPGA 已实现该新路径。
- 后处理候选包括保留所有区域/最大区域、填洞开关和阈值 0.4/0.5/0.6，并保留旧整套策略作对照。新候选不启用开闭运算；最终由验证集选择，优先减少完全失败和 Dice<0.5 的数量，再比较平均 Dice。
- 四宫格最终掩膜使用原图坐标。保存掩膜和叠加图使用同一个最终结果。面积比例和原图面积来自最终掩膜；周长、轴长、不对称度仍在明确标注的 128×128 网络坐标中计算，细化模式先将最终掩膜映射回此坐标。
- 保留旧 `refine=False` 行为和低分辨率硬件掩膜，以便 ABI 和历史结果对照。
- 原图全域有效时跳过有效域大数组和有效域腐蚀；连通域标签用完即释放。新增测试验证该内存优化与原实现的掩膜和标志完全一致。

`ISIC_0001186` 的逐项消融已复现：以 2018 标注计，阈值化 Dice 约 0.546，开闭后约 0.549，最大域操作后为 0。证据是 `postprocess_ablation.json/png`。这不是简单坐标平移；大面积误检覆盖了真正的小目标。

## 复现

以下命令在项目根目录运行。训练环境精确版本见 `artifacts/isic2018/environment.txt`。

```powershell
.\.venv\Scripts\python.exe scripts/improve_isic2018.py prepare --images-zip C:\Users\33879\Downloads\ISIC2018_Task1-2_Training_Input.zip --masks-zip C:\Users\33879\Downloads\ISIC2018_Task1_Training_GroundTruth.zip
.\.venv\Scripts\python.exe scripts/improve_isic2018.py train --epochs 20 --threads 8
# 首次运行可用本机 Visual Studio 构建同源 C++ 核心：
cmd /c scripts\native_core_msvc.cmd
# 使用 PYTHONPATH=software 运行模块导出，不能指向旧发布包内的代码。
$env:PYTHONPATH='software'
.\.venv\Scripts\python.exe -m lesion_fpga.export --checkpoint artifacts/isic2018/checkpoints/best.pt --output artifacts/models/isic2018 --manifest artifacts/isic2018/manifest.json --cache artifacts/isic2018/cache128.npz --calibration 256
.\.venv\Scripts\python.exe scripts/verify_isic2018_export.py
.\.venv\Scripts\python.exe scripts/evaluate_isic2018.py --split validation --int8
.\.venv\Scripts\python.exe scripts/evaluate_isic2018.py --split test --int8
.\.venv\Scripts\python.exe scripts/check_isic2018_failure.py
.\.venv\Scripts\python.exe scripts/package_isic2018.py
.\.venv\Scripts\python.exe -m pytest -q
```

`policy_int8.json` 是验证选择证据；应用读取的 `artifacts/models/isic2018/policy.json` 还需绑定导出的 model_id，并通过量化门槛后再发布。评估报告记录原图 Dice/IoU 和明确约定的边界指标：先将掩膜最大边缩至 512，再计算 2 像素内边界带 IoU。

## 板端限制

未在本轮连接板卡验证。结构未改变不等于上板验收通过。必须核验新权重的逐层一致性、内存、耗时和 HDMI 交互。原图细化的内存随图像面积增加，数据中最大图像超过 3000 万像素，尤其需要在 PYNQ-Z2 上验证；必要时再加入经过一致性验证的分块实现。不要覆盖旧可用模型或重新宣称原有硬件性能指标适用于新路径。
