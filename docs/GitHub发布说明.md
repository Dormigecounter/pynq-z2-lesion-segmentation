# GitHub 发布说明

本仓库是 2026-11-03 从本机工程整理的独立发布副本。原工作目录没有移动或删除。

## 已收录

- Python 应用、训练、量化、评估、测试和部署脚本。
- HLS C++、RTL 快照、Vivado/HDMI 集成脚本及第三方许可证。
- 改进后的模型和最佳微调检查点，以及供原有回归脚本使用的旧模型包。
- 完整 HDMI 位流、HWH、硬件清单及资源和时序报告。
- 技术报告 Word 初稿、操作说明、评估 JSON 和新版真实 FPGA 单图结果包。
- 解包后的首次上板套件及其参考数据。

## 未收录

ISIC 原始数据压缩包、完整训练图像与缓存、虚拟环境、编译目录、SD 卡启动文件/备份、临时排版输出、旧完整发布副本及本地 GitHub 工具/凭据。

数据清单的归档路径保留原实验记录。其他电脑运行训练时需要从合法来源取得数据，并把 ZIP 路径改成自己的实际位置；不能直接复用本机 Downloads 路径。硬件构建脚本中的 AMD 工具路径也需按安装环境调整。

## 验证范围

新版模型 `e71034b765f1de21` 在 217 张内部留出图像上的电脑 INT8 平均 Dice 为 0.8498，IoU 为 0.7669。当前真实 FPGA 结果包只证明单张缩小图的 25 张量和最终掩膜一致；新版 HDMI、多图、大图内存和长期稳定性仍待验收。

首次上板优先阅读 `PYNQ-Z2首次上板_仅USB与电脑.md`。不要格式化存储卡或覆盖已有启动文件。

`PUBLICATION_MANIFEST.json` 记录收录文件的来源散列，用于追溯发布来源。Git 会按 `.gitattributes` 统一文本换行；二进制模型与位流保持字节不变。
